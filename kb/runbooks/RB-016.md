# RB-016: Garbage collection pauses on DataNodes

## Symptom
Long JVM pauses make a DataNode look unresponsive and can trigger heartbeat loss and pipeline failures.

## Likely causes
- Heap too small for the block count.
- Large block reports.
- Memory pressure on the host.

## Checks
1. Check GC logs for pauses over a few seconds.
2. Compare heap size with block count.

## Fix
Increase heap or tune the collector, and reduce block report size.

## Escalate
Escalate if pauses exceed the heartbeat interval.
