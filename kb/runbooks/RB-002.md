# RB-002: Write pipeline failure: could not read from stream

## Symptom
`writeBlock blk_... received exception java.io.IOException: Could not read from stream` means a DataNode lost the connection from the upstream writer or client mid-write.

## Likely causes
- The client or the upstream DataNode died or was killed during the write.
- A network interruption or timeout between pipeline nodes.
- The upstream node was overloaded and closed the socket.

## Checks
1. Find the matching `Receiving block` line to see the pipeline's source and destination addresses.
2. Check the upstream node's logs for a crash, restart or long GC pause at the same minute.
3. Look for a burst of the same exception across several DataNodes, which suggests a network fault.

## Fix
The client normally recovers by rebuilding the pipeline, so a single occurrence needs no action. For repeated failures, fix the network path or the overloaded node, then re-run the failed job.

## Escalate
Escalate when the exception rate climbs across many nodes within a few minutes.
