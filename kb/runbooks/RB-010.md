# RB-010: DataNode lost heartbeat

## Symptom
The NameNode marks a DataNode dead after it misses heartbeats for the configured interval, then starts re-replication.

## Likely causes
- The DataNode process crashed.
- The host lost network.
- Long GC pauses blocked heartbeats.

## Checks
1. Check the DataNode process and host health.
2. Check network reachability from the NameNode.

## Fix
Restart the DataNode. If the node comes back, excess replicas are trimmed automatically.

## Escalate
Escalate if multiple nodes drop at once.
