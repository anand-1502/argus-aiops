# RB-005: Redundant addStoredBlock requests

## Symptom
`Redundant addStoredBlock request received for blk_... on <dn> size <n>` means a DataNode reported a replica the NameNode already has recorded on that node.

## Likely causes
- A block report overlapped with the incremental report for the same replica.
- A retried report after a slow NameNode response.
- A DataNode restart that re-sent reports.

## Checks
1. Check NameNode RPC latency around the report time.
2. See whether the DataNode restarted or re-registered recently.

## Fix
Informational: the NameNode ignores the duplicate. Investigate only if the volume is high, which suggests RPC slowness or report storms.

## Escalate
Escalate if the NameNode RPC queue is backing up.
