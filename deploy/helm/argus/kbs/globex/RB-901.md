# RB-901: Globex escalation: storage on-call rotation

## Symptom
A block failure repeats or affects many nodes and the first-line runbook did not clear it.

## Likely causes
- A failing disk or controller on a Globex storage node.
- A network fault in the Globex data hall.

## Checks
1. Confirm the same node appears in at least three separate failures.
2. Check the data hall switch dashboard for packet loss.

## Fix
Page the Globex storage on-call through the SRE-STORAGE rotation and attach the postmortem.

## Escalate
If two storage nodes fail within an hour, declare a SEV-2 and open the Globex bridge line.
