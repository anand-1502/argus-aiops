# RB-902: Initech change freeze and rollback policy

## Symptom
A failure pattern starts right after a deployment or configuration change.

## Likely causes
- A recent change to HDFS configuration or the client library.
- A rolling restart that overlapped with heavy write traffic.

## Checks
1. Compare the first failure time with the Initech change calendar.
2. Check whether a freeze window is active.

## Fix
During a freeze, roll back the last change through the Initech release tool. Outside a freeze, open an emergency change request.

## Escalate
Ask the Initech platform lead to approve any rollback that touches more than one cluster.
