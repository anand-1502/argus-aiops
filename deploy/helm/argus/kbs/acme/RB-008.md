# RB-008: NameNode in safe mode

## Symptom
In safe mode the NameNode is read-only until enough blocks are reported.

## Likely causes
- Cluster startup waiting for block reports.
- Too many DataNodes missing after an outage.
- Manual safe mode.

## Checks
1. Check the safe mode status and the percentage of reported blocks.
2. Confirm which DataNodes have not registered.

## Fix
Wait for block reports to reach the threshold, or bring missing DataNodes back. Leave safe mode manually only after confirming block health.

## Escalate
Escalate if the reported-block percentage stalls.
