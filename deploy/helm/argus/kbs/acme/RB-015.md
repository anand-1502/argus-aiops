# RB-015: Decommissioning DataNode stuck

## Symptom
A DataNode stays in decommissioning while blocks are still being copied away.

## Likely causes
- Under-replicated blocks that cannot be placed.
- Open files holding blocks.

## Checks
1. List blocks that block decommissioning.
2. Check open files on the node.

## Fix
Wait for replication to finish or close the blocking files.

## Escalate
Escalate if it is stuck for more than a day.
