# RB-009: Slow PacketResponder acknowledgements

## Symptom
A PacketResponder that is slow to acknowledge delays the whole write pipeline.

## Likely causes
- A slow disk on a downstream DataNode.
- Network congestion between pipeline nodes.
- Long garbage collection pauses.

## Checks
1. Compare per-node write latency.
2. Check disk I/O wait and GC logs on the slow node.

## Fix
Replace or exclude the slow node from pipelines, and fix the disk or network cause.

## Escalate
Escalate when write latency stays elevated across the cluster.
