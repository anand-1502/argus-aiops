# RB-014: NameNode RPC latency high

## Symptom
High RPC queue time makes every report and metadata call slow.

## Likely causes
- Block report storms.
- Too few handler threads.
- Namespace lock contention.

## Checks
1. Check RPC queue length and processing time.
2. Check for large directory listings.

## Fix
Stagger block reports and tune handler counts.

## Escalate
Escalate if latency exceeds seconds.
