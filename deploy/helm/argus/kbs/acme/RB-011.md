# RB-011: Corrupt block replica

## Symptom
A replica fails checksum verification during a read or the block scanner.

## Likely causes
- Disk bit rot.
- A faulty disk or controller.
- A partial write.

## Checks
1. Find the replica's DataNode and volume.
2. Check the disk's SMART status.

## Fix
The NameNode re-replicates from a good copy and removes the corrupt one. Replace the disk if corruption repeats.

## Escalate
Escalate if every replica of a block is corrupt.
