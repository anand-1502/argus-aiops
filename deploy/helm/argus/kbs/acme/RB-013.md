# RB-013: Under-replicated blocks backlog

## Symptom
The NameNode keeps a queue of blocks below target replication.

## Likely causes
- A DataNode outage.
- Replication throttling set too low.
- Placement constraints (racks).

## Checks
1. Check the queue size over time.
2. Check replication stream limits.

## Fix
Raise replication limits until the queue drains.

## Escalate
Escalate if the queue grows for hours.
