# RB-006: Empty packet in the write pipeline

## Symptom
`Receiving empty packet for block blk_...` means a DataNode got a zero-length data packet in a write pipeline.

## Likely causes
- A client closed or flushed the stream without data after an aborted write.
- A pipeline recovery sent a marker packet.
- A client bug that emits empty packets.

## Checks
1. Check the client that opened the pipeline and whether the write later completed.
2. Look for pipeline errors before or after the empty packet (see RB-002).

## Fix
Typically benign. If writes fail afterwards, treat it as RB-002.

## Escalate
Escalate only when empty packets accompany failed writes at scale.
